# Original Quran JSON narration-text mirror

Unchanged original Warsh and Qalun (Qaloon) full Quran JSON from
https://quran-json.risanb.com/, by Risan (https://github.com/risan/quran-json).
Each has 114 surahs and 6,214 native ayahs, preserving number_in_hafs mappings.

This source mirrors Quranpedia.net KFGQPC editions. Quranpedia source credit,
original dump versions and source-specific licenses are retained in the unchanged
UPSTREAM-SOURCES.json and UPSTREAM-MANIFEST.json. The original project LICENSE.txt
is retained (CC BY-SA 4.0); underlying publishers retain their stated terms.
Upstream metadata also describes editions not copied to this repository.

These Islamic materials are mirrored for reuse, without ownership claims,
closure, edits, or loss of source attribution. No recitation/audio catalog is copied.
SOURCE.json and CHECKSUMS.sha256 identify the original source URLs, exact bytes,
hashes and retrieval dates. Retrieval is not asserted to be publication date.

Keep older dated snapshots and app-pinned releases even if upstream removes or
changes files. Pull future updates into a review branch and new snapshot; never
perform automatic source-driven deletion. No app code or endpoint is changed here.
